我专注于把复杂、重复的业务流程做成可以运行、复用和持续迭代的 Agent 工具。比起只让 AI 回答问题，我更关心它能否真正连接设备、软件和团队工作流，稳定完成现实任务。

I turn complex, repetitive business processes into agent tools that can run, be reused, and improve over time. I care less about AI that only answers questions and more about systems that connect to devices, software, and team workflows to complete real tasks reliably.

## ⚙️ 技术栈 / Stack

- **AI / Agents：** LLM Agent、Agent Skill、OpenClaw、多 Agent 协作 / LLM agents, agent skills, OpenClaw, multi-agent collaboration
- **自动化 / Automation：** 工作流自动化、客服自动化、飞书集成、REST API / workflow automation, customer-service automation, Feishu integrations, REST APIs
- **移动端 / Mobile：** Android、Accessibility Service、设备远程控制 / Android, Accessibility Service, remote device control
- **内容创作 / Creation：** AI 视频、Prompt Engineering、AIGC 内容工作流 / AI video, prompt engineering, AIGC content workflows
